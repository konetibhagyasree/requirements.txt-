# Student Management System

A simple Python-based Student Management System to add, view, update, delete and search student records.

## 🚀 Features
- Add new student
- View all students
- Search student by ID / Name
- Update student details
- Delete student record
- Data stored in file / list

## 🛠️ Tech Stack
- Python 3.x

## 📂 Files
- `main.py` - Main logic of the system
- `.gitignore` - Ignore cache files
- `README.md` - Project documentation
